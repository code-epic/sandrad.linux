SandraFactory

Agente padre que orquesta la fábrica de software completa

SandraFactory es el sistema centralizado de gestión que coordina todos los proyectos del ecosistema. Gestiona sincronización, estados, análisis de código, respaldos y documentación de manera unificada. Compatible con Bash 3.2+ (macOS) y proporciona una interfaz unificada para administrar los 12 proyectos de la fábrica.

Sincronización Inteligente

Gestiona git remotos de 12 proyectos con una sola línea de comando. Soporta categorías, proyectos individuales y filtros avanzados. Ejecuta add, commit, push y pull de forma automatizada.

sandra-factory sync ecosystem
Git Zero-Trust Historial

Monitoreo Completo

Métricas detalladas: git status (branch, ahead/behind), líneas de código por lenguaje, documentación (README, CHANGELOG), estado de backups y análisis de rendimiento.

sandra-status --compact
LOC Docs Perf

Respaldo Automatizado

Backups comprimidos (tar.gz) por categoría con exclusión inteligente de node_modules, .git, target, dist y archivos temporales. Ubicación: $HOME/backup_sandra/

sandra-factory backup all

SandraEcosystem

Núcleo de la plataforma - 4 proyectos fundamentales

Sandra Server

Middleware/ESB con arquitectura Zero-Trust. Conecta aplicaciones distribuidas, maneja WebSockets (WSHub), gestión documental (ModulosAPP), seguridad AES-256 y gRPC con Sentinel.

Puertos: 80, 443, 8443

go/sandra/
Go 1.24.3

Sandra Sentinel

Motor de cálculo estocástico-determinista para nóminas masivas. Arquitectura hexagonal (Ports & Adapters), usa Tokio runtime y Protobuf v3 para gRPC.

Puerto: 50051 (gRPC)

rust/sandra.sentinel/
Rust 2021

Sandra Console

Panel administrativo con Angular Standalone Components. Módulos: Login, Principal, Redes, Herramientas, Aplicaciones, Seguridad.

Puerto dev: 4200

angular/code-epic.io/v2consola/
Angular 16+

Sandra Desktop

Contenedor desktop combinando Rust backend + Angular frontend. SQLite Cipher con AES-256-GCM encryption y sistema "Alquimia Invisible".

rust/sandra-desktop-container/
Tauri 2.0

Comandos Disponibles

Automatización completa de la fábrica de software

Bash 
$ # Sincronización de proyectos
sandra-factory sync all              # Todos los proyectos (12)
sandra-factory sync ecosystem        # Solo núcleo (4 proyectos)
sandra-factory sync products         # Solo organismos (6 proyectos)
sandra-factory sync contabapp        # Solo Flutter ERP
sandra-factory sync bdv              # Proyecto específico

# Análisis de código
sandra-factory analyze all           # Análisis completo
sandra-factory analyze ecosystem   # Solo ecosistema
sandra-factory analyze bdv --loc    # Líneas de código

# Listado y estado
sandra-factory list                  # Ver todos los proyectos
sandra-factory status ecosystem     # Estado ecosistema

# Backup
sandra-factory backup all            # Backup completo
sandra-factory backup products       # Backup productos

# Help
sandra-factory help                 # Ver ayuda completa
Bash 
$ # Estado de proyectos
sandra-status all                    # Todos los proyectos
sandra-status ecosystem             # Solo ecosistema
sandra-status products              # Solo productos
sandra-status server                 # Proyecto específico
sandra-status ipsfa                   # IPSFA SSSIFANB

# Formatos de salida
sandra-status all --compact        # Vista compacta (tabla)
sandra-status all --json           # Salida JSON
sandra-status server --compact      # Server solo

# Métricas recolectadas:
# - Git: branch, ahead/behind, último commit
# - Código: archivos, líneas por lenguaje
# - Docs: README, CHANGELOG, LICENSE
# - Backup: última fecha y tamaño
# - Rendimiento: node_modules, dist, target
Bash 
$ # Sincronización clásica (legacy)
sandra-sync all                     # Todos los proyectos
sandra-sync ecosystem               # Núcleo (server, sentinel, console, desktop)
sandra-sync server sentinel         # Proyectos específicos
sandra-sync products                 # Productos Angular

# Modo update (solo pull, sin commit/push)
sandra-sync ecosystem -u           # Solo descargar cambios
sandra-sync server -u              # Solo actualizar server

# Con mensaje personalizado
sandra-sync server -m "fix: corregir auth"  # Con commit message
Bash 
$ # Backups por categoría
sandra-backup all                   # Completo (ecosystem + products + contabapp)
sandra-backup ecosystem             # Solo núcleo
sandra-backup products              # Solo organismos
sandra-backup flutter              # Solo Contab ERP
sandra-backup man                   # Solo manuales LaTeX

# Ver backups existentes
sandra-backup list                  # Listar backups

# Exclusiones automáticas:
# node_modules, .git, target, dist, build
# .angular, ios, android, *.log, .DS_Store

# Destino: $HOME/backup_sandra/

Marco Legal Venezuela

Regulación de Tecnologías de Información y Software Libre

Leyes y Decretos

29 Diciembre 2015
Ley del Seguro Social Obligatorio
Gaceta Oficial N° 6.209 Extraordinario.
Regula el sistema de pensiones y jubilaciones del sector público venezolano. Define los regímenes RCP (Régimen de Cargo del Pensionado) y FCP (Familiares del Causante) implementados en Sandra Sentinel.
28 Diciembre 2010
Ley de Infogobierno
Decreto N° 7.664.
Establece los principios rectores para el uso de tecnologías de información en la Administración Pública Nacional. Promueve el software libre y estándares abiertos.
2004
Ley de Patrimonio Cultural
Protección del patrimonio documental digital del Estado. Aplicable a la gestión documental (gdoc) de todos los organismos.
2006
Ley Especial contra Delitos Informáticos
Protección de sistemas informáticos gubernamentales contra accesos no autorizados, interceptación de comunicaciones y sabotaje de sistemas.

InfoGobierno

Principios Fundamentales

  • Soberanía tecnológica

    Preferir soluciones desarrolladas en el país o con tecnologías libres

  • Software libre

    Priorizar soluciones de código abierto con licencia libre

  • Interoperabilidad

    Estándares abiertos para intercambio de datos entre sistemas

  • Seguridad de la información

    Protección de datos personales de los ciudadanos

  • Accesibilidad

    Inclusión digital y acceso universal a la información pública

Cumplimiento SandraFactory: Todos los proyectos cumplen con los principios de InfoGobierno, priorizando software libre (MIT, BSD-3, LPPL) y estándares abiertos (gRPC, REST API).

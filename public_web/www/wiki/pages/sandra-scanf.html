Herramienta de Escaneo: sandra_scanf

sandra_scanf es una herramienta de línea de comandos (CLI) de alto rendimiento diseñada para la gestión masiva de archivos. Sus capacidades van más allá del simple listado, integrando funciones de ciberseguridad, indexación en bases de datos y optimización de almacenamiento mediante deduplicación basada en hash.

Soporta una amplia variedad de formatos (PDF, IMG, DOC, XLS, PPT, EXE, ELF, ZIP, TAR) y está optimizada para ejecutarse en entornos de servidor, permitiendo auditorías de seguridad y organización de activos digitales.

Características Principales

Funcionalidad Descripción Técnica
Integridad Criptográfica Generación de huellas digitales únicas para cada archivo utilizando algoritmos SHA256 y MD5.
Deduplicación Identificación automática de documentos repetidos mediante comparación de hashes, optimizando el espacio de almacenamiento.
Seguridad y Cuarentena Detección de código malicioso con soporte para aislamiento (cuarentena) y análisis en segundo plano (integración con VirusTotal).
Indexación en Base de Datos Capacidad para insertar metadatos y enlaces de los archivos escaneados directamente en la base de datos a través de drivers de conexión.

Sintaxis y Opciones

La herramienta utiliza GNU getopt para el procesamiento de argumentos, permitiendo el uso de banderas cortas y largas.

sandra_scanf [opciones] --path [directorio_o_url]
Opción Corta Opción Larga Descripción y Ejemplo
-p --path Define la ruta del directorio local o URL remota a escanear.
-p /var/www/docs o -p https://dominio.com/archivo.zip
-i --index Define el algoritmo de hash (sha256, md5) o activa la inserción en base de datos.
--index sha256
-r --recursive Activa el escaneo recursivo de subdirectorios. (1 = Activo, 0 = Inactivo).
-r 1
-sl --save-log Genera un archivo de log con los resultados. Valores: infectados, resumen, duplicados.
--save-log infectados
-sdb --save-data ID del driver de conexión para persistir los resultados en la base de datos.
--save-data 60aab142a0f72cf87ed7a056
-u --user Usuario del sistema bajo el cual se evalúa la seguridad o auditoría.
-u admin_sys
-v --verbose Muestra en pantalla un resumen detallado de cabeceras y tipos de archivo procesados.
-v true

Ejemplos de Uso

1. Escaneo Básico de Documentos

Escanear la carpeta de documentos del usuario actual de forma recursiva.

sandra_scanf --path $HOME/Documentos -r 1

2. Auditoría de Seguridad y Logs

Escanear buscando duplicados y posibles amenazas, guardando un log de los archivos infectados.

sandra_scanf -p /var/uploads --index sha256 --save-log infectados

3. Indexación en Base de Datos

Escanear, generar hash SHA256 e indexar los metadatos en la base de datos usando un ID de conexión específico.

sandra_scanf -p /mnt/storage/legal -i sha256 -r 1 --save-data 60aab142a0f72cf87ed7a056

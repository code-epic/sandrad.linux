Motor de Generación de Códigos QR

Sandra Server integra un potente motor para la generación de códigos QR, accesible a través de una API RESTful. Este servicio no es una librería externa, sino una capacidad nativa de la plataforma, diseñada para ofrecer una solución centralizada, segura y flexible para la creación de códigos QR dinámicos.

Concepto e Historia del Código QR

Un código QR (del inglés Quick Response, "respuesta rápida") es la evolución del código de barras tradicional. Se trata de un código bidimensional que puede almacenar una cantidad significativamente mayor de información, desde URLs y texto hasta datos de contacto. Su diseño, basado en una matriz de puntos, permite una lectura omnidireccional a alta velocidad, lo que lo hace ideal para interacciones rápidas con dispositivos móviles.

Fue inventado en 1994 por la compañía japonesa Denso Wave, una subsidiaria de Toyota. Su propósito original no era el marketing, sino mejorar la eficiencia en la industria automotriz.

"El código QR fue desarrollado para permitir el escaneo de componentes a alta velocidad durante el proceso de fabricación de vehículos, superando las limitaciones de los códigos de barras existentes."

Gracias a que Denso Wave liberó la patente, su uso se expandió globalmente y hoy está estandarizado bajo la norma ISO/IEC 18004, lo que garantiza su compatibilidad y fiabilidad en todo el mundo.

Casos de Uso y Actividades Recomendadas

El motor de QR de Sandra Server es lo suficientemente flexible para soportar una amplia gama de actividades de negocio:

Caso de Uso Descripción de la Actividad Ejemplo de Parámetro ruta
Verificación de Documentos Generar un QR en facturas, certificados o contratos que enlace a una página de verificación segura para confirmar la autenticidad del documento. https://api.sandra.com/verify?docId=...
Marketing y Seguimiento Crear QRs para campañas publicitarias que incluyan parámetros de seguimiento (UTM) para medir la efectividad de cada canal (impreso, web, etc.). https://landing.sandra.com/?utm_source=flyer

Descarga de Archivos Segura El QR enlaza a un endpoint de descarga de archivos de Sandra Server, que primero valida el token del usuario antes de servir el fichero. /v1/api/download?fileId=...&token=...

Endpoint: POST /v1/api/makeqr

Este endpoint es el núcleo del servicio de generación de QR. Recibe un cuerpo de solicitud en formato JSON para configurar el código QR a generar y el formato de la respuesta.

Parámetros de la Petición

La petición debe enviar un cuerpo JSON con la siguiente estructura, que corresponde al struct de Go utilizado en el backend: 

{
 id: string
 ruta: string
 tipo: string
}

Los campos del JSON se describen a continuación:

Parámetro Descripción Ejemplo
id Un identificador único para la solicitud o el contenido que se está codificando. Puede ser usado para logging, auditoría o para nombrar el archivo resultante. factura-00123
ruta El contenido principal que se codificará en el código QR. Generalmente es una URL a la que el usuario será redirigido al escanear el código. https://mi-empresa.com/verificar/factura-00123
tipo Define el formato de la respuesta. El servidor puede devolver el QR como una imagen directa o como una cadena de texto codificada. png o base64

Formatos de Respuesta

  • png: Si se especifica tipo=png, el servidor responderá con una imagen en formato PNG. El navegador la interpretará como una descarga de archivo o la mostrará directamente, dependiendo de las cabeceras de respuesta (Content-Type: image/png).
  • base64: Si se especifica tipo=base64, el servidor responderá con un objeto JSON que contiene la imagen del QR codificada en formato Base64. Este formato es ideal para embeber la imagen directamente en una etiqueta <img> en HTML sin necesidad de una solicitud de archivo adicional (ej: <img src="data:image/png;base64,...">).

Ejemplo de Petición

Para generar un QR que enlace a una URL y se devuelva como una imagen PNG, se enviaría una petición POST con el siguiente cuerpo JSON:

POST /v1/api/makeqr
Content-Type: application/json

{
  "id": "doc-456",
  "ruta": "https://api.sandra.com/docs/456",
  "tipo": "png"
}

El servidor respondería con la imagen del código QR, que al ser escaneada, dirigiría al usuario a la URL especificada.
